# fargopy Tutorials

This directory contains a set of tutorials designed to help you get started with `fargopy`. The tutorials are ordered by increasing difficulty.

## Basic Tutorials

- **[Tutorial: animating FARGO3D simulation results](fargopy-tutorial-basics.ipynb)**: Learn how to create animations from your simulation data.
- **[What's in this notebook](fargopy-tutorial-interpolation.ipynb)**: (Interpolation) A guide on how to interpolate simulation fields.
- **[Accretion rate (mass flux)](fargopy-tutorial-flux.ipynb)**: Detailed calculation of mass flux and accretion rates.
- **[Tutorial: configuration variables](fargopy-tutorial-control_fargo3d.ipynb)**: Master the configuration and control of FARGO3D simulations.
